## Architecture and delivery checklist

| Area / initial issue                                                                                     | Intended change                                                                                                                  | Verification / result                                                              |
| -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Web source is in `du-platform-frontend/`, root dependencies and `shared/` are used                       | Move web to `du-platform-frontend/web/`, with owned files and independent configuration                                          | Isolated install/build and import boundary checks: **pending**                     |
| Backend imports root shared code and can serve the web build                                             | Own backend business rules and remove web build dependency; preserve proxy routing                                               | Isolated install/build and API integration: **pending**                            |
| No native application found                                                                              | Implement `du-platform-frontend/mobile/` and real iOS and Android projects                                                       | Independently build and test both native targets: **pending**                      |
| Shared catalogues, validation, SEO and types cross boundaries                                            | Authoritative rules/data in backend; local client presentation/types; versioned API contract                                     | Contract and backwards-compatibility checks: **pending**                           |
| Root manifest/lockfile and shared compiler aliases                                                       | Independent manifests, lockfiles, config, env validation and commands                                                            | Three isolated copies without sibling dependencies: **pending**                    |
| Oracle Docker, Vercel, CI and scripts use root paths; existing working-tree deployment edits are present | Migrate paths without overwriting existing changes; retain rollback and preview isolation                                        | Deployment and release checks, staging where authorized: **pending**               |
| Auth session bootstrap treated every failure as signed out and cached it                                 | Treat unauthorized separately from outages and rate limits; allow retry                                                          | Targeted tests added; full account lifecycle and native session checks **pending** |
| Performance and accessibility not measured for this work                                                 | Measure representative before/after pages, all requested viewport widths, reduced motion, text enlargement and keyboard behavior | Measurements, screenshots and Chromium/WebKit audits: **pending**                  |
| Email, providers and database mutations have external effects                                            | Use controlled test accounts, data and test services                                                                             | Recovery, order persistence, permissions, interrupted requests: **pending**        |

The source inventory does not establish that a feature works. Results must be
updated with actual commands, environment and evidence as implementation proceeds.
